# Konflikt: Badlands – Launcher

Oficjalny launcher serwera DayZ **Konflikt: Badlands**. Jednym kliknięciem **GRAJ** wykrywa Steam i DayZ, sprawdza wymagane mody ze Steam Workshop, pomaga je pobrać i uruchamia grę z modami w kolejności zgodnej z serwerem.

## Pobierz

➡️ **[KonfliktBadlands-Launcher-Setup.exe](https://github.com/rquitr-pixel/badlands-launcher/releases/latest/download/KonfliktBadlands-Launcher-Setup.exe)** (najnowsza wersja, Windows 10/11 64-bit)

Wszystkie wersje: [Releases](https://github.com/rquitr-pixel/badlands-launcher/releases)

Jeśli Windows SmartScreen ostrzeże przed nieznanym wydawcą: „Więcej informacji” → „Uruchom mimo to”. Launcher aktualizuje się sam.

**Wymagania:** Steam z zainstalowanym DayZ.

## Dla administracji

`config/serwer.json` to zdalna konfiguracja launchera (adres serwera i ID modów Szterben ze Steam Workshop). Zmiana tego pliku trafia do graczy bez wydawania nowej wersji launchera.
